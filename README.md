# مشروع النسخ الاحتياطي للمواقع (PHP/MySQL) مع واجهة رسومية

هذا المشروع هو عبارة عن سكربت PHP متقدم مع واجهة ويب رسومية، مصمم لعمل نسخ احتياطية لمواقع الويب التي تعمل بـ PHP و MySQL. النظام سهل التثبيت والاستخدام، ويوفر تحكماً كاملاً في عمليات النسخ الاحتياطي من خلال لوحة تحكم آمنة.

## الميزات الرئيسية

- **واجهة ويب رسومية (GUI)**: لوحة تحكم سهلة الاستخدام لإدارة كل شيء.
- **معالج تثبيت سهل**: واجهة تثبيت ترشدك خطوة بخطوة لإعداد النظام.
- **نظام دخول آمن**: لوحة التحكم محمية بحساب مدير يتم إنشاؤه أثناء التثبيت (باستخدام SQLite).
- **تحكم كامل بالنسخ الاحتياطي**: بدء النسخ الاحتياطي (كامل، قاعدة بيانات فقط، أو ملفات فقط) بنقرة زر.
- **إدارة النسخ المحفوظة**: عرض، تحميل، وحذف النسخ الاحتياطية السابقة مباشرة من لوحة التحكم.
- **عارض سجلات مباشر**: متابعة عمليات النسخ الاحتياطي لحظة بلحظة.
- **استثناء الملفات**: تجاهل الملفات والمجلدات غير المهمة (مثل `node_modules`, `cache`).
- **تنظيف تلقائي (Rotation)**: حذف النسخ الاحتياطية القديمة تلقائياً للحفاظ على مساحة التخزين.
- **رفع عبر FTP**: إمكانية رفع النسخة الاحتياطية إلى سيرفر FTP بعيد.
- **استخدام مزدوج**: إمكانية التشغيل من الواجهة الرسومية أو من سطر الأوامر (CLI) للأتمتة.

## المتطلبات

- PHP 7.2 أو أحدث.
- خادم ويب (مثل Apache أو Nginx).
- الإضافات التالية في PHP يجب أن تكون مفعلة: `pdo_sqlite`, `zip`.
- أداة `mysqldump` مثبتة على السيرفر.

## طريقة التثبيت (الواجهة الرسومية)

1.  **تحميل المشروع**: قم برفع ملفات المشروع إلى سيرفرك.
2.  **توجيه الخادم**: قم بتوجيه الـ "Document Root" الخاص بنطاقك إلى مجلد `public` داخل المشروع. هذا مهم جداً للأمان.
3.  **بدء معالج التثبيت**: افتح متصفحك واذهب إلى رابط موقعك (e.g., `http://your-site.com/`). سيتم توجيهك تلقائياً إلى `install.php`.
4.  **اتبع الخطوات**:
    - **الخطوة 1**: سيقوم المعالج بالتحقق من متطلبات السيرفر وصلاحيات الكتابة. قم بإصلاح أي مشاكل تظهر.
    - **الخطوة 2**: قم بإنشاء حساب المدير الخاص بك (اسم مستخدم وكلمة مرور).
    - **الخطوة 3**: املأ إعدادات النسخ الاحتياطي (معلومات قاعدة البيانات، المجلدات المصدر، إلخ).
    - **الخطوة 4**: سيقوم المعالج بإنهاء التثبيت وحفظ الإعدادات.
5.  **أمان**: بعد التثبيت، يوصى بشدة بحذف ملف `public/install.php` من السيرفر.

## طريقة الاستخدام

- **تسجيل الدخول**: اذهب إلى رابط موقعك وسجل الدخول باستخدام حساب المدير الذي أنشأته.
- **لوحة التحكم**: من خلال لوحة التحكم، يمكنك:
    - بدء عمليات النسخ الاحتياطي.
    - تحميل أو حذف النسخ السابقة.
    - مراقبة سجل العمليات.

## استخدام متقدم (سطر الأوامر و Cron Job)

لا يزال بإمكانك تشغيل السكربت الأساسي من سطر الأوامر، وهو مثالي للأتمتة.

- **للتشغيل اليدوي:**
  ```bash
  # (تأكد من أن ملف config/config.php موجود وتم إنشاؤه عبر معالج التثبيت)
  php /path/to/your/project/src/backup.php
  php /path/to/your/project/src/backup.php --only-db
  php /path/to/your/project/src/backup.php --only-files
  ```

- **للأتمتة باستخدام Cron Job:**
  ```bash
  # افتح crontab
  crontab -e

  # أضف هذا السطر (مع تعديل المسار) للتشغيل اليومي
  0 0 * * * /usr/bin/php /path/to/your/project/src/backup.php >/dev/null 2>&1
  ```
